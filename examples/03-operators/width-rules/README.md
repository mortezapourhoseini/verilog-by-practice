# Example: width, sign and precedence rules

A testbench without a design. It checks the rules from
[chapter 03](../../../docs/03-operators.md): result width, carries,
bitwise vs logical operators, reduction, shifts, signed comparisons,
precedence and integer division.

## Run

```bash
make run DIR=examples/03-operators/width-rules
```

## Try this

Before you run it, cover the expected values and write down your own guess
for each line. Most people get rules 3, 9 and 10 wrong the first time.
