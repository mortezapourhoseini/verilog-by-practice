# Exercise 00.2: half adder

## Task

Complete `half_adder.v`. A half adder adds two bits.

| a | b | carry | sum |
|---|---|---|---|
| 0 | 0 | 0 | 0 |
| 0 | 1 | 0 | 1 |
| 1 | 0 | 0 | 1 |
| 1 | 1 | 1 | 0 |

## Hints

- Look at the table. Which gate gives `sum`? Which gate gives `carry`?
- Write one `assign` statement per output.

## Run

```bash
make run DIR=exercises/00-setup/ex2-half-adder
```
